## ЧАСТЬ 1 — UX/UI СПЕЦИФИКАЦИЯ

---

### 🎨 Дизайн-система

**Концепция:** Soft kawaii meets native iOS. Приложение должно ощущаться как будто его сделал Apple, но потом котик прошёлся лапой по интерфейсу.

**Типографика:**
- Display: `Nunito` (Google Fonts) — мягкие округлые буквы, ощущение уюта
- Body: `Nunito` (тот же, разные веса) — монолитность шрифта = цельность

**Цвета — светлая тема:**
```css
--bg:          #FAFAF7      /* тёплый белый, почти сливочный */
--surface:     #FFFFFF
--surface-2:   #F4F2EE      /* карточки, поля */
--accent:      #FF9BB5      /* розовый кошачий */
--accent-2:    #FFB347      /* тёплый оранжевый — второй акцент */
--text:        #2D2D2D
--text-muted:  #9A9A9A
--border:      #EAE8E4
```

**Цвета — тёмная тема:**
```css
--bg:          #1A1A1F      /* глубокий тёмно-синий, не чёрный */
--surface:     #25252D
--surface-2:   #2F2F38
--accent:      #FF9BB5      /* тот же розовый */
--accent-2:    #FFB347
--text:        #F0EEE9
--text-muted:  #6B6B7A
--border:      #35353F
```

**Анимации:**
- Все переходы: `cubic-bezier(0.34, 1.56, 0.64, 1)` — лёгкий bounce
- Продолжительность: 200–350ms
- Блюр: `backdrop-filter: blur(20px)` везде где нужна глубина

**Иконки:** Только emoji как декор + `lucide-react` для UI-иконок (настройки, назад)

### 🌙 Переключение темы (хедер)

**Расположение:** Правый верхний угол, всегда видим

**Компонент:** Анимированный toggle
- Светлая тема → иконка `☀️` (анимация: вращение + scale out)
- Тёмная тема → иконка `🌙` (анимация: появление + scale in)
- Переход фона: `transition: background 400ms ease`
- Сохраняется в localStorage: `myau_theme`

**Левый верхний угол:** Кнопка настроек `⚙️` — круглая, матовая, 36px

### 🔄 СИСТЕМА RETRY

При следующем открытии приложения — если в localStorage есть записи со статусом `tg_failed` или `ai_failed`:

```
┌────────────────────────────────────┐
│ 🐾  У тебя 2 несохранённые записи  │
│     Отправить в Telegram?          │
│                                    │
│  [Пропустить]    [Отправить все~]  │
└────────────────────────────────────┘
```

**Для каждой записи с `ai_failed`:**
```
"Эта запись не дошла до кошачьего мира (ИИ недоступен).
 Попробовать снова?"
[Да~] [Нет]
```

**Для каждой записи с `tg_failed`:**
```
"Вот это сообщение не улетело в Telegram:

 [превью текста]

 Попробовать снова?"
[Да~] [Нет]
```

Retry идёт по цепочке: если снова фейл — снова тост, счётчик `retry_count` растёт.

Ты — структуризатор записей о еде и жизни. 
Получаешь свободный текст от пользователя + системное время.
Возвращаешь ТОЛЬКО валидный JSON. Без markdown. Без пояснений. Без извинений.

СТРУКТУРА ОТВЕТА:
{
  "time": "HH:MM",
  "day": "День недели на русском",
  "meal_type": "Завтрак | Обед | Ужин | Перекус | Неизвестно",
  "foods": [
    {
      "name": "название продукта/блюда",
      "amount": "количество если указано, иначе null",
      "macros": null
    }
  ],
  "facts": ["строки — всё что не еда но упомянуто"],
  "has_food": true
}

ПРАВИЛА ПО ВРЕМЕНИ:
- Если в тексте есть время ("поел в 3", "в 15:30") — используй его
- Если времени нет — используй системное время из сообщения
- Формат всегда HH:MM

ПРАВИЛА ПО ЕДЕ:
- Есть граммы → записывай точно: "amount": "125г"
- Нет граммов → записывай как есть: "2 шт", "тарелка", null
- НИКОГДА не придумывай граммы сам
- Есть БЖУ на 100г И вес продукта → считай итоговые макросы:
  "macros": {
    "per_100g": {"b": 18, "f": 5, "c": 3},
    "total_weight": "253г",
    "total": {"b": 45.5, "f": 12.7, "c": 7.6}
  }
- Есть только БЖУ на 100г, без веса → записывай как есть, помечай:
  "macros": {
    "per_100g": {"b": 18, "f": 5, "c": 3},
    "note": "на 100г, вес не указан"
  }

ПРАВИЛА ПО ФАКТАМ (facts []):
- Всё что не еда но упомянул пользователь → сюда
- Самочувствие, сон, настроение, случайные события — всё
- Пиши кратко, своими словами, без оценок
- Примеры: "спал 4 часа", "ударился об стул", "устал"

ЕСЛИ ЕДЫ НЕТ ВООБЩЕ:
- "foods": []
- "has_food": false  
- "facts": [всё что написал пользователь, кратко]

СТИЛЬ ЗАПИСИ:
- Все строки на русском
- Названия еды — нормализуй: "говядинка" → "говядина", "кофеёк" → "кофе"
- Сохраняй суть, убирай мат и слэнг из финальной записи
- Краткость: "съел большую тарелку борща" → name: "борщ", amount: "большая тарелка"

javascript
// src/services/llm/index.js
//
// ═══════════════════════════════════════════
//  КАК ДОБАВИТЬ НОВОГО ПРОВАЙДЕРА
// ═══════════════════════════════════════════
//
// 1. Создай файл src/services/llm/myprovider.js
//    Экспортируй одну функцию:
//
//    export const complete = async (messages) => {
//      // messages — массив {role, content} как в OpenAI
//      // верни строку — сырой ответ модели
//      return "строка ответа";
//    }
//
// 2. Добавь провайдер в PROVIDERS ниже
//
// 3. Добавь UI в Settings.jsx — новый таб + нужные поля
//
// 4. Добавь нужные ключи в storage.js (KEYS объект)
//
// Всё. Больше ничего трогать не надо.
// ═══════════════════════════════════════════

import { complete as groqComplete } from './groq.js';
import { complete as ollamaComplete } from './ollama.js';

const PROVIDERS = {
  groq: groqComplete,
  ollama: ollamaComplete,
  // openai: openaiComplete,   ← просто раскомментировать когда будет нужно
  // anthropic: anthropicComplete,
};

export const complete = (messages) => {
  const provider = localStorage.getItem('myau_llm_provider') || 'groq';
  const fn = PROVIDERS[provider];

  if (!fn) throw new Error(`Провайдер "${provider}" не найден`);
  return fn(messages);
}
Вся архитектура теперь держится на одном словаре PROVIDERS. Добавить новый провайдер = создать файл + одна строчка в объект. Никакой магии, никаких if-else цепочек.

Telegram отправка — два запроса:
javascript// telegram.js

export const send = async (text, photo = null) => {

  // 1 — отправляем текст
  const msgRes = await fetch(
    `https://api.telegram.org/bot${token}/sendMessage`,
    {
      method: 'POST',
      body: JSON.stringify({
        chat_id: chatId,
        text,
        parse_mode: 'Markdown'
      })
    }
  );
  const msgData = await msgRes.json();
  const messageId = msgData.result.message_id;

  // 2 — если есть фото, отправляем ответом
  if (photo) {
    const form = new FormData();
    form.append('chat_id', chatId);
    form.append('photo', photo);          // File объект
    form.append('reply_to_message_id', messageId);

    await fetch(
      `https://api.telegram.org/bot${token}/sendPhoto`,
      { method: 'POST', body: form }
    );
  }
}
